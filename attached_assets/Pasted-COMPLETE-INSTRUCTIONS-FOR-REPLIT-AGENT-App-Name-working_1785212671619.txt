App Name (working title): FrameWise
Purpose
An AI tool that helps the user rephrase any request, instruction, or idea so it produces reliable action from a specific person. It accounts for sex-typical differences plus the individual’s history, cognitive style, emotional profile, and known preferences.
Includes a Virtual Relationship sandbox so the user can practice and refine people skills on simulated persons before using the same techniques on real ones.

1. Three Modes

Free-form Mode
Stateless. Only uses information supplied in the current session.
Ongoing Relationship Mode (Real)
Persistent named profiles for real people. Full history, documents, photos, and evolving psychological/operational profile.
Virtual Relationship Mode
Identical system to Ongoing Relationship Mode, but the target is a fully simulated AI person.
User can create virtual people with chosen traits (gender, cognitive style, emotional style, sensitivities, etc.).
The virtual person maintains persistent memory and reacts realistically over multiple sessions.
User practices framing, receives reactions, and gets analytics on what worked.
Same profile reports, Tractatus memory, and optimization tools as real relationships.
Purpose: safe skill refinement.
